# Dino-Game
Dino Game est un mini jeu développé en JavaScript utilisant l’API Canvas.  Le joueur contrôle un dinosaure qui doit sauter pour éviter des obstacles générés aléatoirement. Le jeu est indépendant du FPS grâce à l’utilisation du temps réel (deltaTime), garantissant une expérience fluide sur tous les appareils.
